# KCG GHP Audit Report

แอปกรอกผลตรวจประเมิน GHP ที่สร้างจากเช็กลิสต์ในไฟล์ Excel ต้นฉบับ รองรับการใช้งานบนคอมพิวเตอร์และโทรศัพท์

## เริ่มใช้งาน

วิธีง่ายที่สุด: ดับเบิลคลิก `Start-GHP-App.cmd`

หรือเปิด PowerShell ในโฟลเดอร์นี้ รัน `npm start` แล้วเปิด `http://127.0.0.1:4173`

ข้อมูลจะถูกเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้นโดยอัตโนมัติ ควรส่งออกไฟล์ JSON เป็นระยะเพื่อสำรองข้อมูล

## ความสามารถ

- แบบตรวจ 40 ข้อ แบ่ง 6 หมวด คะแนนเต็ม 80
- เลือกเกณฑ์คะแนนตาม Checklist PD หรือ Definition ในไฟล์ต้นฉบับ
- คำนวณคะแนน ความคืบหน้า และผลผ่าน/ไม่ผ่านอัตโนมัติ
- บันทึกข้อค้นพบและแนบรูปสำหรับรายการที่ไม่ Comply
- เก็บหลายแบบตรวจบนอุปกรณ์เดียวกัน
- ส่งออก CSV, JSON และพิมพ์/บันทึกเป็น PDF

## เผยแพร่ฟรีด้วย GitHub Pages

Repository นี้มี workflow `.github/workflows/deploy-pages.yml` สำหรับเผยแพร่เว็บอัตโนมัติ

1. สร้าง Public repository บน GitHub
2. Push โค้ดขึ้น branch `main`
3. เปิด `Settings → Pages` และเลือก Source เป็น `GitHub Actions`
4. เมื่อ workflow เสร็จ แอปจะอยู่ที่ `https://<username>.github.io/<repository>/`

หน้าแอปเป็นสาธารณะ แต่ข้อมูล Audit และรูปหลักฐานยังเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ถูกส่งขึ้น GitHub
